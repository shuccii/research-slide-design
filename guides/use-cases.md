# 用途別の組み方(学会発表・研究紹介・進捗報告)

どの用途でも「1スライド1イシュー」「タイトルは結論」「出典を付ける」は共通。違うのは、聞き手が何を知っていて、何分あるか。

## 共通の使いやすさ(ユーザビリティ)

| 観点 | 決まり | 理由 |
| --- | --- | --- |
| 読む距離 | 本文 16pt 以上、図中 12pt 以上。余白があれば上限まで大きくする | 会場後方・オンライン縮小表示でも読める |
| 迷子にしない | 全ページに番号。タイトルだけ読めば話の筋が通る | 質疑で「何ページの図」と言える |
| 色覚の多様性 | 色だけで区別しない。マーカー・線種・直接ラベル | 男性の約 5–8% が色覚の多様性をもつ前提で作る [3,8] |
| 白黒印刷・プロジェクタの色ずれ | 白黒で意味が通るか、グレースケールで確認する | 配布資料・古いプロジェクタ |
| 再利用 | 数式は LaTeX を残す。図は SVG/PDF と生成スクリプトを残す | 論文・ポスターへ転用できる |
| 配布 | PDF で配る(フォントが埋め込まれる) | Windows では書体が置き換わる |
| アクセシビリティ | 図に代替テキスト、式に LaTeX の代替テキスト | 読み上げ・検索に対応 |

## 学会発表(口頭)

- 枚数の目安: **発表時間(分)× 1 枚**。12 分なら 10–12 枚+予備。
- 構成: 表紙 → 背景と問い(1–2)→ 手法(1–2、`method` / `equation`)→ 結果(3–5、`figure-notes` / `two-figures` / `figure-table`)→ まとめ(`summary`)→ 参考文献 → 予備スライド(質疑用の詳細表・追加図)。
- 結果ページは「主張 1 つ+根拠の図 1–3 枚+要点数値」。比較は同じ軸・同じ色・同じ名前で。
- 予稿・要旨と数値・用語を一致させる。発表前に共著者・指導者の確認と発表練習を入れる。

## 研究紹介(ラボ見学・面接・異分野向け)

- 枚数: 5–8 枚。専門外の聞き手を想定し、背景を 1 枚増やす。
- 構成: 表紙(`cover` の右側に要点 3 行)→ 何が困っているか(数値で 1 枚)→ どう解くか(模式図 1 枚、`guides/figures.md`)→ 何が分かったか(`key-numbers`)→ 今後 → 参考文献。
- 専門用語は初出で一言説明を注に。式は 1 本までにし、変数表で意味を書く。

## 進捗報告(研究ミーティング)

- 枚数: 3–8 枚。前回からの差分を中心に。
- 構成: 前回の課題と今回やったこと(`dense-table` で一覧)→ 結果(`figure-notes`)→ 分からないこと・相談したいこと(alert で 1 か所)→ 次にやること。
- 暫定値は「暫定」と明記し、確定した値と分ける。

## ポスターに転用するとき

スライドの図(SVG/PDF)と表をそのまま使い、文字はポスターの規定(通常 24pt 以上)に合わせて描き直す。縮小・拡大だけで済ませない。
