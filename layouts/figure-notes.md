# figure-notes — 図 1 枚 + 要点数値

- 使う場面: 1 つの図が主張の根拠になるとき。
- 図: 見出しなしで本文の上端から。直下に図の注(略語の説明・データの区分・誤差棒の意味)。
- 要点数値: 角丸の面(`number_box`)に ラベル → 数値 → 比べる相手。1 列に 1 つ。
- 3 つ目を足すなら読み取り 1–2 行(`label`)。
- 16:9: 図 4 列 : 数値 2 列。
- 4:3: 図 2 列 : 数値 2 列(図が小さくなるなら数値を下に回さずページを分ける)。
- 見本: `examples/build_sample.py` p.2。

共通: タイトル `title` 32pt W6+英語 18pt(結論を 1 文、1 行)、一言メッセージ 20pt+英語 14pt、2.08 in に罫線。本文 2.25–6.68 in、出典欄 6.82 in(`caption` 14pt、短い形)。要素は 3 つまで、余白は残してよい。日本語の各文の直下に英語訳。ビルダーの警告が 0 件になるまで文を短くするかページを分ける(`DESIGN.md`)。
