# cover — 表紙

- 使う場面: 発表の題・要点・発表者を示す。
- 上から: 短い線 → 題 `cover-title` 40pt(2 行まで)+英語 22pt → 副題 `cover-sub` 24pt+英語 → 区切り線 → 「本発表の要点」2–3 項目(`label` 20pt+英語)→ 発表者・所属・日付(`body`、1–2 行)。
- 要点には p.n や数値の出どころを書けるようにしておく。見本データなら副題に明記する。
- 16:9: 全幅に縦に並べる。
- 4:3: 全幅に縦に並べる。題は全角約 18 字で 2 行に収める。
- 見本: `deck.cover()`。

共通: タイトル `title` 32pt W6+英語 18pt(結論を 1 文、1 行)、一言メッセージ 20pt+英語 14pt、2.08 in に罫線。本文 2.25–6.68 in、出典欄 6.82 in(`caption` 14pt、短い形)。要素は 3 つまで、余白は残してよい。日本語の各文の直下に英語訳。ビルダーの警告が 0 件になるまで文を短くするかページを分ける(`DESIGN.md`)。
